Grader Agent

Portfolio demo for educators: upload a Markdown rubric, then grade PDF submissions (text extracted, up to {{ pdf_max_pages }} {% if pdf_max_pages == 1 %}page{% else %}pages{% endif %}), or single text / audio answers (audio is transcribed before scoring). Outputs are suggestions — teachers remain responsible for final marks and fairness.
