# Sample inputs

This folder holds **example rubrics** you can upload through the web UI (or copy into your local `data/rubrics/rubrica_activa.md` after setting `GRADER_DATA_DIR`).

- `rubrics/rubrica_activa.md` — course-style rubric with weighted criteria (Spanish).
- `rubrics/rubrica_ieee_activa.md` — same content under a second filename for experiments.

The app does **not** read these files automatically; they are documentation-friendly copies for demos and tests.
